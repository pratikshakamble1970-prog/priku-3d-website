# Priku Website Designs — animated demo

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling, rotating 3D-inspired shapes and motion
- `script.js` — scroll reveal and pointer interaction

## Publish on Cloudflare Pages from a phone
1. Sign in to GitHub and create a new repository (for example, `priku-website`).
2. Upload these three files to the repository's root folder (not inside an extra nested folder).
3. Sign in to Cloudflare and open Workers & Pages → Create → Pages → Connect to Git.
4. Choose the repository. For a plain HTML/CSS/JS site, leave the build command blank and set the output directory to `/` if the interface requests it.
5. Deploy. Cloudflare will provide a `*.pages.dev` link.

## Before sharing with clients
- Replace `hello@example.com` in `index.html` with your own business email or WhatsApp contact link.
- Prices are example starting prices; edit them to match your real offer.
- Portfolio items are illustrative demo concepts, not real client work.
- This is a static front-end demo. A real checkout, booking system, contact form backend, or e-commerce inventory requires additional setup.
- A free host cannot guarantee uninterrupted service forever. Keep a copy of these files and renew any custom domain on time.
